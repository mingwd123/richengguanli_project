  ```bash
  mkdir -p "$WS" && cd "$WS" && npm install agent-browser --no-fund --no-audit
  "$WS/node_modules/.bin/agent-browser" install    # 下载 Chrome 153 到 C:\Users\ming\.agent-browser\browsers
  ```
  调用时始终用 `$WS/node_modules/.bin/agent-browser`（不在 PATH 上）。
- 首次 `open` 可能静默失败（exit 1 无输出），加 `--debug` 再试即可成功。

### 关键命令

- `open <url>` / `reload` / `close`；`snapshot -i` 拿 ref；`click eN` / `check eN` / `fill eN "text"` / `select eN value`。
- 原生 `<select>`、`<input type=datetime-local>` 在 snapshot 里常常没有名字，**用 `eval` 直接设值 + 派发 `input` 事件**最稳：
  `eval '(() => { const i=document.querySelector(".modal-panel input[type=date]"); i.value="2026-09-25"; i.dispatchEvent(new Event("input",{bubbles:true})); })()'`
- `set viewport <w> <h>`（注意是 `set viewport`，不是 `viewport`）；`screenshot <path>`（`--full-page` 不支持）。
- 检查横向溢出：`eval 'JSON.stringify({w:document.documentElement.clientWidth, o:document.documentElement.scrollWidth-document.documentElement.clientWidth})'`。
- 截图默认落在 `C:\Users\ming\.agent-browser\tmp\screenshots\`，产出交付用的图要显式传路径。
