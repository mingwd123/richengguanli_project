# 用户端计划 v2.1：负荷量化与差异化增强版

> 编写日期：2026-08-26
> 适用范围：`src/web-user` 用户网页端（及复用其页面的桌面端工作台）
> 前置基线：MVP、V1.1、V1.2 已完成（个人日程、分组、日历、团队任务、通知、AI 草稿、疲劳评估等）
> 说明：本计划只描述用户端及其所需后端/数据库配套；AI 收费、管理端、桌面端专属能力分别见独立计划。

---

## 一、版本目标

v2.1 的核心不是堆新功能，而是**把「疲劳评估」这个差异化能力从一个"凭感觉打分"的表单，升级成有真实工时数据支撑的负荷管理闭环**，同时堵住两个明显的用户流失缺口。

重点方向：

1. 为个人日程补齐「预计投入时间 / 实际投入时间」与跨多天精确分摊，让负荷计算从"按归属日期粗算"升级为"按时长量化"。
2. 把团队任务纳入个人负荷视图（至少按归属人折算），修复"一用协作，护城河就失效"的逻辑断层。
3. 补齐「周期 / 重复任务」这一效率工具的基础能力，降低用户流失。
4. 新增「周 / 月疲劳与负荷回顾报告」，把日终调查沉淀成持续可回看的价值。
5. 把 AI 从"解析 / 拆解 / 建议"的被动翻译，升级为基于疲劳系数的「主动排程建议」。
6. 提供日历 iCal 订阅 / 导出，降低用户迁移与导入成本。

## 二、数据库与后端变更

### 2.1 预计 / 实际投入时间

| 变更 | 说明 |
|------|------|
| `schedule.estimated_minutes` | 个人日程预计投入时长（分钟，可空） |
| `schedule.actual_minutes` | 个人日程实际投入时长（分钟，可空），完成时由用户填写或默认等于预计 |
| `schedule.span_allocated` | 是否已按跨天区间分摊（布尔，用于区分"单日归属"与"多日分摊"） |
| 新增 `schedule_allocation` 表 | 跨天日程的逐日分摊明细：`schedule_id`、`alloc_date`、`alloc_minutes` |

规则约定：

- 默认仍按现有"归属日期"计算负荷，保证向后兼容；一旦填写 `estimated_minutes` 或跨天区间，切换到时长分摊口径。
- 跨天分摊采用"按自然日切分 + 按分钟占比"的方式，先把总时长按每天所占区间切块，再落到对应日期。
- 实际投入时间的填写必须经过确认，不默认覆盖；日终调查新增一个"今日实际投入（可手动修正）"字段。

### 2.2 团队任务纳入负荷

- 团队任务新增可选字段 `estimated_minutes`（预计投入时长）。
- 新增"负荷归属人"口径：团队任务的负荷计入**每位执行人（assignee）**名下，而非创建者。
- 个人负荷接口（首页 / 日程负荷摘要）新增可选参数 `include_team_tasks`，默认开启，返回"个人日程 + 分配给我的团队任务"合并负荷。
- 边界保持不变：团队任务仍**不参与**日终调查训练与疲劳提醒的个性化校准（避免团队协作波动污染个人疲劳基线）。本版本只做"负荷可见 + 汇总"，不做"纳入训练"。

### 2.3 周期 / 重复任务

| 变更 | 说明 |
|------|------|
| `schedule.rrule` | RFC 5545 规则字符串（`FREQ=DAILY/WEEKLY/MONTHLY` 等），可空表示非重复 |
| `schedule.series_id` | 重复系列标识，同一系列的多次实例共享 |
| `schedule.occurrence_date` | 当前实例实际归属日期 |

规则约定：

- 创建重复日程时，后端按 `rrule` 生成未来 N 次实例（N 默认 30，可配置）。
- 完成 / 取消单个实例不波及其他实例；支持"修改本实例"与"修改整个系列"两种编辑入口。
- 系列删除时级联清理未发生实例，已完成实例保留。

### 2.4 疲劳回顾报告

- 复用现有 `fatigue_survey`、`schedule`、`schedule_allocation`、`team_task` 表，不新增主表。
- 新增只读聚合接口：按周 / 月返回平均疲劳分、峰值日、负荷均值、完成率、疲劳趋势曲线。

### 2.5 日历订阅

- 新增只读接口 `GET /api/v1/schedules/ical`，返回标准 iCal（`.ics`）格式。
- 每用户一个订阅 Token（`subscribe_token`），无需登录即可只读订阅，可随时重置。

## 三、开发阶段

### 阶段 1：预计 / 实际投入时间与跨天分摊 — P0

#### 后端
- [ ] `schedule` 增加 `estimated_minutes`、`actual_minutes`、`span_allocated` 字段（Flyway migration）。
- [ ] 新增 `schedule_allocation` 表与分摊写入逻辑。
- [ ] 日程创建 / 编辑接口支持传入预计时长与跨天区间，写入分摊明细。
- [ ] 个人负荷计算切换为"时长口径优先、归属日兜底"。
- [ ] 日终调查接口新增"今日实际投入"可修正字段。
- [ ] 负荷试算（创建前预览）同步改为时长口径。

#### 用户端
- [ ] 创建 / 编辑日程表单新增「预计投入时长」与「开始 / 结束时间」输入。
- [ ] 跨天日程编辑时展示逐日分摊预览。
- [ ] 完成日程时弹出「实际投入时长」确认（默认等于预计，可改）。
- [ ] 首页负荷摘要按新口径展示。

#### 验收标准
- [ ] 填写预计时长后，负荷值按分钟精确计算，不再只按"有几个日程"粗算。
- [ ] 跨天日程按天正确分摊，各天负荷之和等于总时长。
- [ ] 旧数据（未填时长）仍按归属日期口径展示，不报错。

### 阶段 2：团队任务纳入负荷 — P0

#### 后端
- [ ] 团队任务增加 `estimated_minutes` 字段。
- [ ] 团队任务负荷按执行人归属，支持"分配给我的团队任务"负荷汇总。
- [ ] 个人负荷接口新增 `include_team_tasks` 参数并默认开启。

#### 用户端
- [ ] 首页 / 日程负荷摘要展示"个人 + 分配给我的团队任务"合并负荷。
- [ ] 团队任务卡片显示预计投入时长。
- [ ] 明确标注团队任务负荷"仅汇总、不参与疲劳校准"的提示。

#### 验收标准
- [ ] 用户被分配团队任务后，首页负荷随之增加，按执行人而非创建者归属。
- [ ] 团队任务不参与日终调查训练与疲劳提醒校准（保持现有边界）。
- [ ] `include_team_tasks=false` 时行为与旧版一致。

### 阶段 3：周期 / 重复任务 — P0

#### 后端
- [ ] `schedule` 增加 `rrule`、`series_id`、`occurrence_date` 字段。
- [ ] 新增重复日程生成、单实例完成 / 取消、系列编辑与删除接口。
- [ ] 列表与日历视图支持展示重复实例。

#### 用户端
- [ ] 创建日程时可选"重复：每天 / 每周 / 每月 / 自定义"。
- [ ] 编辑重复日程时提供"仅此实例 / 整个系列"选择。
- [ ] 日历与时间轴正确展示重复实例。

#### 验收标准
- [ ] 重复日程按规则生成未来实例，单实例操作不波及其他实例。
- [ ] 系列编辑 / 删除行为正确，已完成实例保留。
- [ ] 重复实例在日历、首页、时间轴三处数据一致。

---

### 阶段 4：周 / 月疲劳与负荷回顾报告 — P1

#### 后端
- [ ] 新增周 / 月聚合接口，返回疲劳分均值、峰值、负荷均值、完成率、趋势曲线。
- [ ] 数据聚合做时间边界（自然周 / 自然月）与空数据兜底。

#### 用户端
- [ ] 新增「回顾」入口，按周 / 月切换查看。
- [ ] 展示疲劳趋势折线、负荷柱状、峰值日标注、完成率。
- [ ] 空数据时给出引导文案，避免空白页。

#### 验收标准
- [ ] 周 / 月切换正确，数据边界准确。
- [ ] 趋势曲线与日终调查原始数据一致。
- [ ] 无数据时不报错，展示引导。

---

### 阶段 5：AI 主动排程建议 — P1

#### 后端
- [ ] 在 AI 建议接口中接入用户疲劳系数与当前负荷，输出"建议挪动 / 压缩"的结构化建议。
- [ ] 建议仍只返回草稿，不直接写库，遵守隐私开关。

#### 用户端
- [ ] 首页 AI 建议区新增"排程建议"：高负荷日提示"把 X 挪到 Y、压缩 Z 到 N 分钟"。
- [ ] 建议项支持一键应用到日程草稿，用户确认后保存。

#### 验收标准
- [ ] AI 建议基于真实疲劳系数与负荷，而非泛泛文案。
- [ ] AI 不直接写库，确认后才保存。
- [ ] 关闭 AI 数据记录后不保存输入输出。

---

### 阶段 6：日历 iCal 订阅 / 导出 — P1

#### 后端
- [ ] 新增 iCal 导出接口，按用户订阅 Token 生成 `.ics`。
- [ ] 订阅 Token 支持查看与重置。

#### 用户端
- [ ] 「设置」新增"日历订阅"：展示订阅链接、一键复制、重置 Token。

#### 验收标准
- [ ] 订阅链接可被系统日历 / Google Calendar 正常解析。
- [ ] 重置 Token 后旧链接立即失效。

## 四、接口增强清单

- [ ] `POST/PUT /api/v1/schedules` 支持 `estimatedMinutes`、`actualMinutes`、跨天区间。
- [ ] `GET /api/v1/schedules/load-summary` 支持 `includeTeamTasks`。

- [ ] `GET /api/v1/fatigue/report?period=week|month` 疲劳回顾聚合。
- [ ] `GET /api/v1/schedules/ical?token=xxx` 日历订阅。
- [ ] `GET/POST /api/v1/schedules/subscribe-token` 查看 / 重置订阅 Token。
