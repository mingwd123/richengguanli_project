# 桌面端计划 v2.2.1：常驻工作台与系统级体验版（补强）

> 编写日期：2026-08-26
> 适用范围：`src/desktop` Tauri 桌面端（复用用户端页面 + Rust 层）
> 前置基线：桌面端已完成四视图、负荷摘要、日终调查、快捷时间轴、系统托盘、置顶、透明度和原生通知，并在 Windows 150% 缩放下实机验收通过。
> 版本说明：在 v2.2 基础上补充常驻基本盘、全局搜索启动器、悬浮待办、任务栏角标、专注联动勿扰与崩溃日志等新发现的能力空白；依赖用户端的新功能（负荷量化、回顾报告、iCal 订阅等）随 v2.1 交付后自动生效。

---

## 一、版本目标

桌面端的价值不在"再做一个 Web"，而在**系统级常驻能力与可靠性**。v2.2.1 围绕三条主线：

1. **补齐发布门禁**——版本化安装包、自动更新和缩放回归，让桌面端真正可分发。
2. **补全常驻基本盘**——开机自启、单实例、窗口记忆、跟随系统主题，让桌面端从"偶尔打开"变成"常驻后台随叫随到"。
3. **做系统级差异化**——全局快捷键录入、全局搜索启动器、托盘倒计时、专注计时、悬浮待办、离线缓存。

重点方向（按优先级）：

- P0：版本化安装包 + 自动更新；开机自启 + 单实例；窗口位置/大小记忆；跟随系统深色模式；全局快捷键快速录入。
- P1：全局搜索启动器；托盘倒计时 + 专注计时 + 系统勿扰联动；桌面悬浮迷你待办；离线优先本地缓存。
- P2：任务栏角标 + 剪贴板记录；崩溃日志收集上报。

### 阶段 2：常驻基本盘（开机自启 + 单实例 + 窗口记忆 + 跟随系统主题）— P0

- [ ] 跟随系统深色模式：监听系统主题变化，自动切换日间 / 夜间主题（保留手动覆盖）。
- [ ] 桌面偏好面板新增"开机自启动"开关。

#### 验收标准
- [ ] 开启自启动后，系统登录即后台运行。
- [ ] 重复点击启动图标不会多开，而是聚焦已有窗口。
- [ ] 关闭再打开后窗口位置、大小与显示器归属保持一致。

#### 用户端 / 交互层
- [ ] 快速录入窗口支持极简模式：标题 + 时间 + 紧急度，一键保存。
- [ ] 录入成功后短暂提示并自动收起窗口。

#### 验收标准
- [ ] 应用在后台时，按全局快捷键即可呼出录入窗口。
- [ ] 一句话录入（含 AI 解析）流程顺畅，保存后主窗口同步刷新。
- [ ] 快捷键可自定义，冲突有提示。

- [ ] 托盘菜单新增"最近待办倒计时"，显示最近一条未完成日程的剩余 / 逾期时间。

- [ ] 专注结束 / 休息时通过原生通知提示。

#### 验收标准
- [ ] 托盘倒计时数据准确，完成操作即时生效。
- [ ] 专注计时可启动、暂停、结束，时长能回填实际投入时间。
