## 2. JWT 升级

- 引入成熟 JWT 库，例如 `jjwt` 或 `java-jwt`
- 替换当前手写 HMAC token 生成/解析逻辑
- 标准化 claims：userId、tokenType、role、exp、jti
- 支持管理员 token 和普通用户 token 区分

## 3. 登录限流

- 实现登录失败计数
- 维度：IP + 手机号/用户名
- 规则：10 分钟内失败 5 次则限制登录
- 超限返回 429
- 登录成功后清除失败计数

## 4. Refresh Token 轮换与失效

- 每次 refresh 后旧 refresh token 立即失效
- refresh token 增加 jti 或版本号
- 服务端保存 refresh token 状态
- logout 时撤销当前 access token / refresh token
- 增加过期 token 清理逻辑

## 5. 提醒扫描定时任务

当前只有 `POST /api/v1/internal/reminders/scan` 手动扫描接口，缺少自动扫描。

- Application 增加 `@EnableScheduling`
- 新增 `ReminderScanTask`
- 使用 `@Scheduled` 定时调用提醒扫描逻辑
- 保留手动扫描接口作为调试/补偿入口

## 6. 对象级权限统一化
