# 管理端计划 v2.3.1：数据视图与风控增强版（合并）

> 编写日期：2026-08-26
> 适用范围：`src/admin-web` 管理后台（及所需后端配套）
> 前置基线：管理后台已具备资源列表、详情、统计概览、审计日志、超级管理员权限控制与 AI 多 Key 配置池。
> 版本说明：在 v2.3（运营看板 / 备份监控 / AI 配额 / 账号风控）基础上，合并新增「六大类数据视图体系」，重点补齐管理端目前缺失的"图表式观察"能力，并以疲劳 / 负荷视图为核心差异化。**AI 收费单独讨论，不纳入本计划**（AI 成本仅做"成本可见与额度控制"的技术准备，不涉及定价与支付）。

---

## 一、版本目标

管理端目前是"资源管理 + 审计日志 + AI Key 池"，本质是**清单式管理**。v2.3.1 的目标是升级为**图表式观察**：让管理员不仅能"查到有多少"，还能"看懂趋势、分布、下钻与预警"。

两条主线：

1. **补观察维度**——建立「运营健康 / 协作任务 / 疲劳负荷 / AI 成本 / 系统运维 / 安全风控」六大类数据视图，每类是一组可下钻的图。
2. **守住成本与安全**——AI 成本配额控制、账号风控、备份监控，与数据视图互为补充。

重点方向（按优先级）：

- P0：疲劳 / 负荷视图（核心差异化）；运营健康视图；备份与监控只读面板。
- P1：协作任务视图；AI 成本视图与配额控制；账号风控。
- P2：系统运维视图；安全风控视图。

---

## 二、数据视图体系（新增核心）

> 设计原则：不在 Dashboard 一页堆满，而是「运营总览」+ 侧边栏「数据视图」二级菜单，六大类做成独立可下钻页面，每页支持时间范围切换（今日 / 近 7 天 / 近 30 天 / 自定义）。数据源基本复用现有表，主要是新增聚合 SQL + 前端图表（Element Plus + ECharts）。

### 2.1 疲劳 / 负荷视图（P0，核心差异化）

- **全站疲劳分布直方图**：`fatigue_survey` 的 0~100 分按区间聚合，观察整体疲劳水位。
- **调查完成率**：每日"应填调查" vs "实际已填"，衡量疲劳模块激活率。
- **高负荷用户预警列表**：负荷接近 / 超过个人承受上限的用户，支持管理者主动介入。

### 2.2 运营健康视图（P0）

- **用户增长曲线**：按日 / 周的新增注册折线（`user.created_at`）。
- **活跃与留存**：DAU / WAU、次日 / 7 日留存。
- **用户状态分布**：active / disabled / 未验证邮箱占比。

### 2.3 协作任务视图（P1）

- **任务流转漏斗**：创建 → 已接受 → 已完成，定位协作卡点。
- **完成率趋势**：按时完成 vs 逾期 vs 取消，按日折线。
- **团队规模分布**：各团队人数直方图，识别活跃团队与僵尸团队。

### 2.4 AI 成本视图（P1，为 AI 收费打地基）

- **调用趋势**：调用次数、Token 消耗、估算成本三条线（`ai_usage_log`）。
- **功能使用分布**：AI 解析 / 任务拆解 / 今日建议 / 描述优化各占比。
- **Key 池健康**：各 Key 调用量、失败率、切换次数。

### 2.5 系统运维视图（P2）

- **健康仪表盘**：API 延迟、DB 连接、错误率、磁盘 / 内存。
- **备份状态**：最近备份时间、是否异地，只读展示。

### 2.6 安全风控视图（P2）

- **异常登录**：异地 / 高频失败登录，风险等级标记。
- **注册来源分析**：按时间 / IP 段识别批量注册。

## 三、后端变更

### 3.1 数据视图聚合

- 新增聚合接口，基于现有 `user`、`team`、`schedule`、`team_task`、`fatigue_survey`、`ai_usage_log`、`notification` 等表统计。
- 统一时间范围参数与口径，接口只读，不落库、不误改数据。

### 3.2 备份与监控

- 新增只读"系统状态"接口：数据库最近备份时间、磁盘 / 内存使用、容器健康、最近错误日志数。
- 备份执行沿用运维脚本（见《部署记录》），管理端只做状态展示与告警阈值提示，不直接触发破坏性操作。

### 3.3 AI 成本与配额控制

- 在 `ai_usage_log` 基础上增加成本估算字段（按模型单价估算，可配置）。
- 新增配额维度：每用户 / 每团队 / 全局的每日 AI 调用次数或成本上限。
- 新增超限处理：达到阈值后拒绝调用并返回明确业务码，同时写告警日志。
- 配额规则由管理员在后台配置，支持启用 / 停用与阈值调整。

### 3.4 账号风控

- 新增异常登录检测：同账号异地 / 高频失败登录记录，标记风险等级。
- 新增账号封禁 / 解封接口（复用现有用户状态管理并补审计日志）。
- 新增注册来源分析：按时间 / IP 段统计注册来源，识别批量注册。
