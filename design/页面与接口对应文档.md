# 日程提醒 App — 页面与接口对应文档

> 用于前后端对接，描述每个页面需要调用的接口、展示字段、提交字段和权限按钮。

---

## 1. 登录页

页面路由：`/login`

| 动作 | 接口 |
| --- | --- |
| 登录 | `POST /api/v1/auth/login` |

提交字段：
- `phone`
- `password`

成功后：
- 保存 `accessToken`、`refreshToken`。
- 拉取用户资料或直接进入首页。

## 3. 首页 / 我的任务总览

页面路由：`/`

| 页面数据 | 接口 |
| --- | --- |
| 今日个人日程、今日团队任务、未读数、分组 | `GET /api/v1/home/today` |
| 7天内即将到期 | `GET /api/v1/home/upcoming` |
| 未读消息数刷新 | `GET /api/v1/notifications/unread-count` |

展示字段：
- 个人日程：`id`、`title`、`groupName`、`timeType`、`startTime`、`endTime`、`deadlineTime`、`status`。
- 团队任务：`id`、`title`、`teamName`、`groupName`、`startTime`、`deadlineTime`、`status`、`assignStatus`。
- 前端计算：倒计时、逾期展示、时间轴展示类型。

页面操作：
- 新建个人日程：跳转 `/schedules/new`。
- 新建团队任务：跳转 `/team-tasks/new`。
- 点击任务：进入对应详情页。
- 标记日程完成：`PUT /api/v1/schedules/{id}/complete`。
- 团队任务接受/拒绝/完成：调用团队任务状态接口。

---

## 4. 日历页

页面路由：`/calendar`

| 页面数据 | 接口 |
| --- | --- |
| 月视图数据 | `GET /api/v1/schedules/calendar?year=2026&month=7` |
| 某日详情 | 可复用 `GET /api/v1/schedules` 和 `GET /api/v1/team-tasks/my` 日期筛选 |

展示要求：
- 日期格子显示待办数量、已完成数量。
- 右侧当日时间轴展示个人日程和团队任务。
- 时间轴区分 `point_event`、`deadline_task`、前端推导的 `duration_task`。

## 6. 新建 / 编辑个人日程页

页面路由：
- `/schedules/new`
- `/schedules/:id/edit`

| 动作 | 接口 |
| --- | --- |
| 创建 | `POST /api/v1/schedules` |
| 详情 | `GET /api/v1/schedules/{id}` |
| 保存修改 | `PUT /api/v1/schedules/{id}` |

提交字段：
- `title`
- `description`
- `groupName`
- `timeType`
- `startTime`
- `endTime`
- `deadlineTime`
- `remindAts`

表单规则：
- `point_event`：必须有 `startTime`，`endTime` 可选。
- `deadline_task`：必须有 `deadlineTime`。
- `deadline_task + startTime + deadlineTime`：前端展示为持续任务。

---

## 7. 团队列表 / 团队详情页

页面路由：
- `/teams`
- `/teams/:id`

| 页面数据/动作 | 接口 |
| --- | --- |
| 我的团队 | `GET /api/v1/teams` |
| 创建团队 | `POST /api/v1/teams` |
| 加入团队 | `POST /api/v1/teams/join` |
| 团队详情 | `GET /api/v1/teams/{id}` |
| 成员列表 | `GET /api/v1/teams/{id}/members` |
| 修改角色 | `PUT /api/v1/teams/{teamId}/members/{userId}/role` |
| 移除成员 | `DELETE /api/v1/teams/{teamId}/members/{userId}` |
| 重新生成邀请码 | `POST /api/v1/teams/{id}/regenerate-invite-code` |

权限按钮：
- owner：显示修改角色、移除成员、重新生成邀请码。
- admin：显示移除普通成员。
- member：不显示成员管理按钮。

## 10. 团队任务详情页

页面路由：`/team-tasks/:id`

| 页面数据/动作 | 接口 |
| --- | --- |
| 任务详情 | `GET /api/v1/team-tasks/{id}` |
| 接受任务 | `POST /api/v1/team-tasks/{id}/accept` |
| 拒绝任务 | `POST /api/v1/team-tasks/{id}/reject` |
| 完成任务 | `POST /api/v1/team-tasks/{id}/complete` |
| 取消任务 | `POST /api/v1/team-tasks/{id}/cancel` |
| 恢复任务 | `POST /api/v1/team-tasks/{id}/restore` |
| 重新分配 | `POST /api/v1/team-tasks/{id}/reassign` |
| 修正执行人状态 | `PUT /api/v1/team-tasks/{id}/assignees/{assigneeId}/status` |

权限按钮：
- 创建者、owner/admin：编辑、修改时间、取消、重新分配、修正状态、删除。
- 执行人：接受、拒绝、完成，仅操作自己的 active assignee。
- cancelled 任务：隐藏执行人操作。
